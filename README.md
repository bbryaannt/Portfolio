# 🌸 A little bouquet for you

[**Open the animated flower bouquet →**](https://bbryaannt.github.io/Portfolio/bouquet/)

A small browser adaptation of the spinning ASCII flower bouquet. Daisies, tulips, a wrapped bouquet, ribbon, floating hearts, and sparkles—all animated right in your browser.
